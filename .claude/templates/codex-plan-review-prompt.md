# Codex 計画レビュープロンプト

以下の実装計画をレビューしてください。

## レビュー観点

1. **バグ・脆弱性リスク**: 計画通りに実装した場合にバグや脆弱性が生じる設計上の問題はないか
2. **スコープの妥当性**: 過不足なく適切なスコープか、やり残しや不要な作業はないか
3. **技術的な実現可能性**: 選択した技術・ライブラリ・パターンは適切か、既知の落とし穴はないか
4. **依存関係の見落とし**: 影響範囲に漏れはないか、暗黙の依存は存在しないか
5. **テスト計画の十分性**: テストケースは主要なパスとエッジケースをカバーしているか

## 回答形式

- **日本語で回答**してください
- 忖度禁止 — 問題があれば断言してください
- 各指摘は以下の分類で記載:
  - 🔴 必須: バグ・脆弱性・データ損失リスク
  - 🟡 推奨: 設計改善・可読性・パフォーマンス
  - 🟢 参考: スタイル・命名・ドキュメント
- 指摘がない場合は「指摘なし」と明記してください
