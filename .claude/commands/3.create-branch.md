GitHub Issue $ARGUMENTS 用のブランチを作成してください。

---

## 手順

### 1. Issue情報の取得

```bash
gh issue view $ARGUMENTS --json title,number
```

### 2. ブランチ名の生成

以下の命名規則に従ってブランチ名を決定:

```
feature/issue-{番号}-{タイトル要約}
```

例:
- `feature/issue-123-add-user-auth`
- `feature/issue-45-fix-login-bug`

**ルール:**
- 小文字のみ
- スペースはハイフンに変換
- 50文字以内に収める
- 英数字とハイフンのみ

### 3. ブランチ作成

```bash
# 最新のmainを取得
git fetch origin

# mainから新しいブランチを作成
git checkout -b feature/issue-$ARGUMENTS-{要約} origin/main
```

### 4. 確認

```bash
# 作成したブランチを確認
git branch --show-current

# リモートにプッシュ（任意）
git push -u origin $(git branch --show-current)
```

---

## 注意事項

- ブランチ作成前に `/2` で計画が立てられていることを推奨
- 既にブランチがある場合は作成をスキップ
- worktree 使用時は `/a` でブランチも同時に作成される

## 関連コマンド

- `/2`: 計画立案
- `/a`: worktree作成（ブランチも作成）
- `/4`: 実装開始

Remember to use the GitHub CLI (`gh`) for all GitHub-related tasks.
