新しいGitHub Issueを作成してください。

**CLAUDE.md の開発フローに従って進めてください。**

## 使い方

タスクの内容を伝えてください。以下の情報があると良いです：

- 何を実現したいか
- 背景や理由
- 完了条件

## Issueテンプレート

```bash
gh issue create --title "[タイトル]" --body "$(cat <<'EOF'
# Issue: [タイトル]

## 背景
[なぜ必要か]

## 目的
[何を実現したいか]

## 受け入れ条件
- [ ] [どうなれば完了か]
EOF
)"
```

## ラベル追加

Issueの内容に応じてラベルを付与してください（最低2つ）：

**優先度ラベル（1つ選択）:**
- `High`: 1〜2営業日以内に対応すべき重要タスク
- `Medium`: 通常の機能追加やバグ修正
- `Low`: 将来的に対応で良い小変更

**内容ラベル（1つ以上選択）:**
- `バックエンド`: API やサーバーサイド実装
- `フロントエンド`: UI/UX 実装・修正
- `テスト`: テストコードの追加・修正
- `インフラ`: インフラ基盤の構築・設定
- `ドキュメント`: ドキュメントの作成・更新
- `バグ`: 不具合の修正

```bash
gh issue create --title "..." --body "..." --label "Medium" --label "バックエンド"
```

## 注意事項

- Issue作成後、`/2` で実装計画を立案してIssue本文に追記
- 詳細は CLAUDE.md を参照

Remember to use the GitHub CLI (`gh`) for all GitHub-related tasks.
