# ブランドガイドライン（テンプレート）

プロジェクトのUIデザインにおけるブランドガイドラインのテンプレートです。
プロジェクト固有のカラー・フォント・コンポーネント方針を定義してください。

## カラーパレット（70/25/5 配色理論）

### メインカラー

| 役割 | 使用比率 | 用途 | カラー |
|------|:--------:|------|--------|
| ベース | 70% | 背景、余白、カード背景 | `#FFFFFF` / `#F9FAFB` |
| メイン | 25% | サイドバー、ボタン、見出し | `#XXXXXX`（プロジェクトに合わせて設定） |
| メインダーク | - | ホバー状態、ロゴ背景 | `#XXXXXX` |
| アクセント | 5% | CTA、重要通知、バッジ | `#XXXXXX` |

### CSS変数（差し替え可能設計）

```css
:root {
  /* ブランドカラー - プロジェクトに合わせて変更 */
  --brand-primary: #XXXXXX;
  --brand-primary-dark: #XXXXXX;
  --brand-accent: #XXXXXX;

  /* セマンティックカラー */
  --success: #10b981;
  --warning: #f59e0b;
  --muted: #737373;
  --destructive: #e7000b;

  /* UI変数（ブランドカラーを参照） */
  --sidebar: var(--brand-primary);
  --sidebar-foreground: #ffffff;
  --primary: var(--brand-primary);
  --ring: var(--brand-primary);
}
```

### セマンティックカラー

| 用途 | 説明 | カラー |
|------|------|--------|
| 成功 (success) | 有効、完了、成功 | `#10b981`（エメラルド） |
| 警告 (warning) | 保留、注意、失敗 | `#f59e0b`（アンバー） |
| 無効 (muted) | 解約済、終了 | `#737373`（グレー） |
| エラー (destructive) | 削除、危険操作 | `#e7000b`（レッド） |
| 情報 (info) | 案内、リンク | メインカラーと同色 |

### テキストカラー

| 用途 | 説明 | 推奨値 |
|------|------|--------|
| foreground | 本文テキスト | 濃いグレー（gray-800相当） |
| muted-foreground | 補足説明、プレースホルダー | 中間グレー（gray-500相当） |

## デザイン原則

### 1. 清潔感・信頼感
ユーザーに安心感を与えるデザイン。
- 余白を十分に取る（70%はベースカラー）
- 原色を避け、彩度を落とした色を使用
- 影は控えめに

### 2. シンプルさ
情報過多を避け、必要最小限に。
- 1画面1目的
- 重要な情報を目立たせる
- 不要な装飾を排除

### 3. 一貫性
同じ操作は同じUIパターンで。
- ボタンスタイルの統一
- フォーム要素のレイアウト統一
- エラー表示の統一

### 4. アクセシビリティ
すべてのユーザーが利用できるように。
- コントラスト比 4.5:1 以上確保
- フォーカス状態の明示
- 適切なラベル付け

## コンポーネント使用指針

### ボタン

| バリアント | 用途 | 使用例 |
|-----------|------|--------|
| default (primary) | 主要アクション | 保存、送信、作成 |
| secondary | 副次アクション | キャンセル、戻る |
| outline | 第三のアクション | エクスポート、詳細を見る |
| destructive | 危険な操作 | 削除、無効化 |
| ghost | インラインアクション | 編集、コピー |

### バッジ

| バリアント | 用途 | カラー |
|-----------|------|--------|
| default (primary) | デフォルト | メインカラー |
| success | 有効、完了、成功 | `#10b981`（エメラルド） |
| warning | 停止中、注意、失敗 | `#f59e0b`（アンバー） |
| muted | 無効、終了 | `#737373`（グレー） |
| destructive | 削除、危険な操作 | `#e7000b`（レッド） |
| secondary | 補足情報 | `#f5f5f5`（薄グレー） |

### カード

- ヘッダー: タイトル + 説明（オプション）
- コンテンツ: メイン情報
- アクション: ボタン群（右寄せ）
